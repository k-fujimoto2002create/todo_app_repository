# todo_app_repository

CLI上で起動するToDoアプリ

## 特徴

- 特徴1 タスク追加機能
- 特徴2 タスク一覧表示機能
- 特徴3 完了したタスク機能
- 特徴4 タスク削除機能
- 特徴5 データ保存機能
- 特徴6 データ読み込み機能

## 必要環境

- Python 3.13.9以上
- Anaconda3 2025.12-2以上
- macOS / Windows / Linux

## 使い方

```
conda activate
python ~
```

python の後ろにmain.pyの絶対パスを入力します

ファイルアプリからドラッグ&ドロップでコピー可能
